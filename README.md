# Python Week 2 — Simple Bill Calculator

An interactive Python program that asks the user for an item name, price, and quantity, then calculates and displays the total using an f-string.

## File

- `bill_calculator.py` — the program

## How to run

    python3 bill_calculator.py

## Example

    What is the item name? Notebook
    What is the price of one item? 50
    How many items do you want? 3

    You are buying 3 x Notebook.
    3 items at 50.00 each = 150.00

## Concepts used

- `input()` — collect text input from the user
- `float()` and `int()` — convert strings to numbers
- Arithmetic — multiply price by quantity
- **f-strings** — `f"...{variable}..."` to embed values in text
- Formatting — `:.2f` to show two decimal places
- `print()` — display the result
